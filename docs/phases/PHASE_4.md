# Phase 4 — Production & D2C Launch (Weeks 11–16)

## Goals
Launch commercially **only after demand signal**.

## Commercial gate (must pass before 500-unit SMT)
- Working demo video + alpha testimonials
- Landing page live
- Target: ~50 paid deposits OR equivalent strong preorder/waitlist evidence
- Unit economics sheet updated with real COGS from revA

If gate fails: build-to-order / 50–100 batch instead of 500.

## Manufacturing
- SMT PCBA for `dash-s35`
- Enclosure batch (3D print or molding decision from alpha feedback)
- Packaging + insert QR to docs / dash.aether.dev
- QC script: flash, screen test, encoder test, USB enum test

## Ops (India)
- Payments: Razorpay / Cashfree
- Shipping: Shiprocket / D2C fulfillment
- Support FAQ: browser requirements, USB cables, OS notes

## Open source launch
- Public firmware + hardware repos (or keep umbrella if not yet split)
- Tagged releases: `fw-0.x`, `web-0.x`, `hw-dash-s35-revA/B`
- Contributor guide linked from storefront

## Exit criteria
- First customer shipments
- Public docs + flashing guide
- Support channel live (email/Discord/GitHub discussions)
- Postmortem: what to build next (`mini28` vs themes vs gamer mode)
