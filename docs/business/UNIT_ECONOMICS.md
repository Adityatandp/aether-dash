# Unit Economics (Working Draft)

India D2C assumptions for launch SKU `dash-s35`. Update after revA quotes.

## Target retail
- **MRP / sell price:** ₹4,999 (band ₹4,499–₹5,999)

| Item | INR (est.) |
|---|---|
| ESP32-S3 module | 250–450 |
| 3.5" IPS panel + FPC | 450–800 |

| Passives / USB-C / LDO / ESD | 80–150 |
| EC11 + knobs | 40–80 |
| Enclosure (FDM/batch) | 150–350 |
| Packaging + insert | 40–80 |
| **COGS subtotal** | **≈ ₹1,260–₹2,360** |

## Contribution sketch @ ₹4,999

| Line | INR |
|---|---|
| Price | 4999 |
| COGS (mid) | -1800 |
| Payment + shipping contrib. | -350 |

## Preorder gate
- Prefer **≥50 paid deposits** before 500-unit inventory
- If weak: run 50–100 unit batch build-to-order

## KPI targets (first 90 days post-launch)
- Refund/DOA < 5%
- Support tickets / unit < 0.3
- Creator demo videos ≥ 10
