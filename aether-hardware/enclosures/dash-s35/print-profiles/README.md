# Print profiles (dash-s35)

Suggested FDM starter settings:
- Material: PETG (desk durability) or PLA for fit checks
- Layer: 0.2 mm
- Infill: 25–40% (heavier base preferred)
- Supports: yes for angled back
- Orientation: base on bed

Export STEP from CAD when dimensions stabilize; keep OpenSCAD parametric for community remixes.
