# dash.aether.dev

Planned production host for `aether-web-app`.

## Environments
- Local: `npm run dev` → `http://localhost:5173`
- Alpha: staging subdomain (TBD)
- Prod: `https://dash.aether.dev`

## Requirements
- HTTPS (Web Serial / PWA)
- Static hosting (Cloudflare Pages / Netlify / Vercel / Firebase)
